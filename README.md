# Lluvia de estrellas

Juego cooperativo para dos jugadores en el mismo teclado. Abre `index.html` en el navegador (no necesita instalar nada).

- **Papá** (🐻, mitad izquierda): `A` y `D`
- **Sofía** (🐰, mitad derecha): `←` y `→`
- `ESPACIO`: empezar / pausa

Atrapad estrellas (⭐ +1, estrella dorada +3, arcoíris +5) y esquivad las nubes de tormenta (quitan un corazón). Cuando cae el corazón rosa en los dos lados, si lo atrapáis los dos en menos de 3 segundos: **¡Chócala! +10**. Cada 20 estrellas subís de nivel, recuperáis un corazón y cambia el paisaje.

Sofía tiene cesta más grande, menos nubes y objetos algo más lentos.
